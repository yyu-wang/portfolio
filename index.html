丽境 AI 平台

AI Agent 开发 2026.01 – 2026.07

鞋服设计需同时对接多家大模型供应商，Agent 协议各异、工具调用状态分散——主导打造覆盖「Agent 对话 → 工具消费 → 智能生图 → 图像编辑 → 趋势洞察」全链路的 AI Agent 平台，独立实现前端 + Python Agent 层双端：前端交互与事件消费、Python 执行编排与多模型调度（Java 服务负责业务数据）；设计Agent 事件消费层，双通道整合 SSE 事件流与 REST 业务数据，服务鞋服箱包行业设计师。 AI 功能日均调用超万次

  • Python Agent 层：独立实现 ReAct 主循环——思考 → Function Calling 工具路由 → 执行 → 反思；内置三家供应商（Kondo / AgentPro BTY / 斑头雁）协议适配器，统一暴露 Function Calling 工具接口；多模型并行调度（Gemini / GPT / Seedream 三条生图通道，局部改款走 FLUX），失败自动降级；SSE 流式推流 + 步数熔断
  • 前端协议归一化 + 事件消费层：三家供应商流式协议收敛为统一事件模型 AgentStreamEvent（思考 / 工具 / 正文 / 追问 / 完成），新增供应商只需扩展解析器，消费层与 UI 零改动
  • 工具状态聚合：按 tool_id 实时聚合并发工具的执行状态，每类工具配专属消费组件（工具气泡 / 思考块 / 追问），事件驱动五阶段渲染，AbortSignal 贯穿取消链路
  • 多模型并行生图：Python 侧并行调度 Gemini / GPT / 字节 Seedream 三条生图通道，局部改款走 FLUX；前端逐帧分槽渲染 + 预占位 + 乱序回填，多条调用聚合为同组 UI
  • 移动端重构：独立 Vue3 + Vite 移动端工程，嵌入钉钉工作台（免登授权与容器适配），把 PC 端绝大部分能力对齐到移动端
  • 端侧推理与性能：onnxruntime-web 在浏览器内运行 Segment Anything，点击分割生成蒙版，驱动 AI 局部重绘；Canvas 2D / Fabric.js 支撑图像编辑，Three.js 做 3D 预览；万级节点脑图渲染与按行虚拟滚动保持 60fps

KingPilot · 企业级 ERP 智能 Agent

独立开发 2026

面向企业 ERP 的智能 Agent 平台（厂商中立）：自然语言查询 / 写入业务单据，ERP 适配层以 Protocol 契约解耦厂商。源码：github.com/yyu-wang/kingpilot

  • Agent 五阶段主循环：记忆 → 规划 → 安全护栏 → 执行 → 反思，步数熔断；反思续跑与重复指令防御，LLM 答复经数字事实 / 工具来源 / 业务一致性三重幻觉校验后输出
  • 厂商中立 ERP 适配层：ErpClient Protocol 契约（查询 / 写动作 / 资源释放三方法），工厂按配置装配厂商实现；新增厂商只需「实现协议 → 声明端点 → 工厂注册」三步，Function Calling 工具由适配层统一暴露
  • fail-closed 安全体系：工具过滤 + 6 类 Guard 管道（实体 / 限额 / 参数 / Schema / SQL）+ 权限引擎 + 风险引擎；高危写操作强制进入人工审批网关（HITL）——审批中心持久化 + 双人复核状态机 + 中断后幂等恢复执行
  • 治理闭环：黄金集离线评测 → 发布门禁逐指标判定，指标回退 fail-closed 拒绝发布；语义缓存只复用只读计划；成本按 token 档位聚合控预算；Badcase 处理台标记 / 脱敏 / 一键导出评测集，线上 badcase 回流评测闭环
  • 内置 RAG 知识库：业务文档分块摄入 → 本地 BM25 索引（增量更新）→ 注册 kb_search 工具，回答强制引用来源、无命中明确兜底不编造
  • 写操作安全与工程：Saga 事务倒序补偿、请求幂等、写台账 Hash Chain 防篡改；多租户隔离（租户上下文 + 存储隔离 + 越权测试）与密钥热轮换（File / Vault Provider）；金蝶沙箱模拟器零依赖联调、Web 控制台（会话调试 / 审批 / Trace / 成本看板）、106 个 pytest 测试模块覆盖安全攻击注入与 LLM 宕机混沌
