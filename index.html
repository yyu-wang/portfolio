// 解决什么问题

接 AI 能力的前端有两类脏活：供应商 SSE 协议不一致（每接一家改一遍 UI）、 多模型并行生图乱序返回（图片位置随返回顺序跳动）。 本仓库把这两类问题的解法沉淀为可独立使用的模块。

// 核心设计

  • 双层解析架构：OpenAI 扁平 chunk / Agent 嵌套 delta / 大写扁平事件三种协议，归一化为一套 AgentStreamEvent —— 新增供应商 UI 层零改动
  • 槽位调度器：start 预占位 + 乱序回填 + 通道内游标，comfyui / gemini / gpt 三通道并行布局稳定不跳动

// 生产踩坑沉淀

  • 完成判定只能由 event:complete 触发 —— model_result 的 isLast 只代表单通道结束
  • 幽灵请求治理：generation 计数器，被取代的旧流迟到帧不污染新任务
  • 取消 ≠ 清空：已出图保留 / 未出图标记已取消，三种终态互不覆盖
  • mock SSE 服务器真实时序模拟，零后端即可完整体验 demo

// 工程质量

  • vitest 27 个单测覆盖协议解析与调度状态机
  • GitHub Actions：typecheck + test + build 全绿
